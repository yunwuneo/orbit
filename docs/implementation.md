本地验证：55 项自动化测试通过；macOS Python 3.14.7，另以 `TZ=Asia/Tokyo` 运行同套测试通过。包含 `.env` 加载、配置优先级、日期索引与完整时间、未来计划保护、补写查重及脱敏连接诊断。未据此宣称已在 Linux Python 3.11 实测。

本地测试命令：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -v
```

单元测试中的 Notion REST 模拟服务保留属性形状、分页、筛选、更新与丢失回执；模型输出为可控数据。另行执行的 `tests/live_acceptance.py` 使用真实服务完成 12 项检查。**这些样本不证明真实模型已长期稳定满足所有角色与叙事要求**。

实现不包含聊天 UI、社交平台、主动通知、Koishi、自动补剧情或真实服务器操作。没有新建虚拟环境、安装依赖或复制历史档案。测试使用的临时数据库自动清理。

技术参考采用 Notion 官方 [数据源查询](https://developers.notion.com/reference/query-a-data-source)、[页面更新](https://developers.notion.com/reference/patch-page)及[块更新](https://developers.notion.com/reference/update-a-block)；REST 适配器固定 `Notion-Version: 2025-09-03`，使用 `data_source_id`，正式联调仍须验证该版本在目标工作区的实际行为。
